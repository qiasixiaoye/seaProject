# 本地海洋知识文档说明

当前目录保存的是可被本地 RAG 读取/迁移到 RAGFlow 的海洋知识摘要文档，不是论文全文下载库。

已纳入 `data/ocean_knowledge.json` 的来源包括：

- NOAA Ocean Acidification Overview
- NOAA Fisheries: Understanding Ocean Acidification
- Marine heatwaves under global warming
- Marine heatwaves threaten global biodiversity and ecosystem services
- IPCC SROCC Summary for Policymakers

后续如果要做严肃 RAGFlow 知识库，应把 PDF、HTML 正文或正式报告文件放入此目录，再通过 RAGFlow Web 上传建库。
